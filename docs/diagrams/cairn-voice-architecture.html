How Compass
Answers the Phone

with Amazon Connect
Cairn Outdoor Co. · Agentforce Voice · Code with Sally

* added on feature/data360-enhancement. Everything else was already the contact center, or the sample data, on main.

01

The call

Three questions Cairn hears all day.

Caller on the phone
Where's my order?
What's the return policy?
How do I light the stove?

On main, a person answered every one of these.

02

Amazon Connect

Cairn's phone system. Salesforce joins the call.

Amazon Connect numbers, IVR, audio
Service Cloud Voice softphone + transcript
VoiceCall the call, in Salesforce

The switch stays. Compass is inserted in front of the people who already work these queues.

03

Who's calling *

Cairn Inbound runs before Compass speaks.

Caller number from the VoiceCall
Phone lookup PersonAccountPhoneLookup
Exactly one? else stay unknown
Route to Compass Omni-Channel

One Person Account match writes Account and first name onto the VoiceCall. Zero or many, and Compass has no name yet.

04

Compass *

The router never answers. It only picks a topic.

Hi Maria — this is Compass with Cairn Outdoor.
Agent Router one hand-off per turn
Order Lookup status, returns
Company FAQ policy and hours
Product Q&A specs and how-tos

Off topic and unclear get no answer. “Talk to a person” starts in Company FAQ, not in a transfer.

05

Data 360 *

Main loaded the records. This branch is what reads them.

Order lookup

“Where’s my order?”

Apex action OrderLookupDataGraph
Data graph Compass_Order_Lookup

Account → Order → Product · hourly

CRM records mapped by hand

Known caller hears number, total, status, and date. Unknown caller needs the order number and the date, then hears status and date only.

Company FAQ

“What’s the return policy?”

Apex action CompanyFAQVectorSearch
Vector index Cairn_Knowledge
Knowledge articles returns, shipping, warranty

Replaced Answer Questions with Knowledge. Compass queries the vector index directly and speaks only from what comes back.

Product Q&A

“How do I light the stove?”

Apex action ProductQnAHybridSearch
Hybrid index Compass_Product_QnA
Manual PDFs one or more per product

Keyword plus vector, so a phrase like “won’t ignite” still ranks. No data graph on this path.

06

Person or case *

Only a topic can hand the call off.

Can't answer from a topic
Escalate says it and transfers
Connect queue Orders & Returns · Customer Support
Human picks up in Salesforce
if nobody is free
Create Case Cairn_Create_Case
Case number read back on the call

Order lookup transfers to Orders & Returns. FAQ and product questions transfer to Customer Support. The queue is still Amazon Connect.
